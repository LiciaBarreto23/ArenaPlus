# Arena+
Gestão e reserva de quadras esportivas. 

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema para **gestão de uma Arena Esportiva**, com o objetivo de centralizar e facilitar o gerenciamento das atividades realizadas no espaço.

O sistema contempla diferentes perfis de acesso, como **atletas/usuários, funcionários e administradores**, oferecendo funcionalidades específicas para cada perfil.

Entre as principais funcionalidades estão:

* Autenticação e cadastro de usuários;
* Visualização de painéis e informações gerais;
* Reserva e gerenciamento de quadras;
* Acompanhamento de reservas e atendimentos;
* Comunicação por meio de mensagens;
* Gerenciamento das operações da Arena;
* Visualização de indicadores administrativos;
* Configurações e gerenciamento das informações da Arena.

## Protótipos

Este repositório apresenta os **protótipos das principais telas do sistema**, desenvolvidos para representar a estrutura, navegação e funcionalidades previstas para a aplicação.

Os protótipos estão organizados de acordo com as principais funcionalidades do sistema e são acompanhados por **Issues no GitHub**, utilizadas para registrar e acompanhar o desenvolvimento de cada conjunto de telas.
